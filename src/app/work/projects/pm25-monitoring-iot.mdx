## Overview

Designed and developed as an Air Quality Researcher in the IPB University Climatology Lab, this prototype was built to make PM2.5 observations more accessible in environments where continuous monitoring is limited.

## System architecture

- **Sensor:** DSM501 PM2.5 dust sensor
- **Microcontroller:** ESP32
- **Storage:** microSD module and local SQL database
- **Interface:** HTML/PHP local web dashboard

## Features

- Real-time PM2.5 monitoring
- Local data logging for offline access
- Sorting, filtering, download, and visualization
- Serial data parsing and environmental sensor integration

## Potential applications

The architecture can support community-based air-quality monitoring, urban pollution mapping, and citizen-science initiatives in under-monitored or high-risk environments.
